# Project Instructions

## Project

Data Analytics Dashboard is built with Python, Django, SQLite, HTML, CSS, and JavaScript.

## Development Guidelines

- Follow Django best practices, including Django's conventions for apps, models, views, URLs, templates, forms, settings, and security.
- Keep code clean, readable, and organized. Use clear names and place functionality in the appropriate modules.
- Explain important code changes in your completion summary, including what changed and why.
- Avoid unnecessary dependencies. Prefer the Python standard library and existing project dependencies when practical.
- Never delete or overwrite existing files without asking the user first. Preserve existing work and check before replacing file contents.
- After implementing a feature or fix, run the appropriate tests and report the commands run and their results. If tests cannot be run, explain why.

## Project Stack

- Backend: Python and Django
- Database: SQLite
- Frontend: HTML, CSS, and JavaScript
